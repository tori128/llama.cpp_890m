The three-generation TG average improved by 13.72%. All six requests reached the 300-second generation limit; the recorded output token counts are the values at that limit. The benchmark JSON is included as `docs/flash-next-formal-20260919.json`.

## Conditions

- 32,768 prompt tokens, 4,096-token response cap, cold request followed by two prompt-cache requests.
- Batch 2,048, u-batch 512, context 100,000.
- MTP enabled: nmax 3, pmin 0.75. Main and draft KV cache: Q8_0.
- Vulkan, `--load-mode mmap`, `--no-host`, `--no-repack`, `LLAMA_PLE_HOST_GATHER=0`, and `LLAMA_MMAP_RANDOM=1`.
- The adopted binary has no `--lazy-mode` option. The comparison removed that unsupported option at launch while retaining mmap and no-host loading.
- CPU governors were already `performance`. GPU DPM `high` was unavailable. Peak temperatures were 87 °C for the baseline and 88 °C for the adopted build.
- Model and draft file SHA-256 values are recorded in the benchmark JSON generated with the measurement.
