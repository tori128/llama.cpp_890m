# Radeon向けllama.cppの性能測定

## 変更点

llama.cppの上流master `51a77c4f24`を基準に、Radeon向けの変更を積み直しました。HIPのMoE処理順序には上流実装を使います。F16 Flash Attentionの修正、量子化KV用のFlash Attention、RDNA3.5の量子化行列演算、共有KVの修正は引き続き含まれます。

Linux ROCm版はgfx1150、gfx1151、gfx1102を1つのアーカイブで提供します。iGPU単独とeGPU+iGPUで同じ`llama-server`を使えます。GPU間の直接転送を無効にしてビルドしています。SalukiのeGPU+iGPU測定では`LLAMA_DFLASH_DEV=0`でDFlashの特徴データをRAM経由で転送しました。

CI build commit: `dc6ef3fb62b4a125799cec8dea661db173d95f82`

Linux ROCm archive SHA-256: `6033677f0adf6acdaa34ac32e6fa74aa589a41a37650de7c3ab700b18d9d6786`

[配布物を生成したGitHub Actions](https://github.com/tori128/llama.cpp_890m/actions/runs/44498770950)

## 測定条件

Ryzen AI 9 HX 370、Radeon 890M、RX 7600M XT、Linux、ROCm 10.0.0。配布するLinux ROCmアーカイブを展開し、その実行ファイルと共有ライブラリで測定しました。コンテキスト131,072、Flash Attention有効、同時処理数1、CPUスレッド10です。同じ32,768トークンをキャッシュなしで1回、キャッシュを再利用して2回処理しました。各回の生成は4,096トークンで、生成時間の上限は600秒です。PPは初回の入力処理速度、TGは3回の生成速度の算術平均です。所要時間の集計からモデルの読み込みを除きました。
