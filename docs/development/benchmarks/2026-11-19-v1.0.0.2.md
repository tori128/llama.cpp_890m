## 性能

Radeon 890MとRX 7600M XTで、32Kトークンの入力に対して4Kトークンを3回生成しました。2回目以降は入力キャッシュを再利用しました。表は同じ設定で測定した更新前のローカル版からの変化です。合計時間にはモデルの読み込みを含めていません。

| モデル | GPU | 入力処理（tok/s） | 生成（tok/s） | 合計時間（秒） |
| --- | --- | ---: | ---: | ---: |
| Qwen3.6 35B | iGPU | 497.72 → 491.46 | 25.75 → 19.49 | 559.58 → 705.79 |
| Qwen3.6 35B | eGPU+iGPU | 480.62 → 502.53 | 35.03 → 36.11 | 419.25 → 405.75 |
| Saluki 27B | iGPU | 101.92 → 99.41 | 11.33 → 8.93 | 1406.56 → 1706.29 |
| Saluki 27B | eGPU+iGPU | 134.80 → 134.28 | 16.24 → 16.33 | 1015.47 → 1012.64 |

Qwen3.6のiGPU単独で2Kトークンを生成する追試では、30.26 → 30.87 tok/sでした。4Kトークンを3回生成した際の低下の原因は未特定です。
