# Qwen3.8 Flash-Next: PR #28123 benchmark report

Date: 2026-09-03

## Scope

- Candidate: [llama.cpp PR #28123](https://github.com/ggml-org/llama.cpp/pull/28123), `qwen4exp: support recurrent state rollback` (merged 2026-09-01).
- Backend: Vulkan.
- Runtime configuration: the active Qwen3.8 Flash-Next shortcut configuration, including MTP + n-gram draft decoding (`nmax=4`), B2048/U512, and Q8 KV cache.
- Input: a tokenized programming task of exactly 32,768 tokens.
- Output metric: the complete first 4,096 generated-token interval, then stop.
- Controls: same seed in each pair, alternating order, a new server process per sample, and prompt-cache reuse and allocation disabled.

## Measurements

| Pair | Baseline prefill tok/s | Candidate prefill tok/s | Prefill delta | Baseline 4K generation tok/s | Candidate 4K generation tok/s | 4K generation delta | GPU peak delta |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 1 | 108.68 | 90.41 | -16.81% | 6.13 | 5.77 | -5.74% | +0.32% |
| 2 | 98.42 | 92.72 | -5.79% | 6.44 | 6.45 | +0.24% | -0.02% |
| 3 | 101.86 | 87.80 | -13.81% | 6.17 | 6.14 | -0.58% | -0.05% |

- 4K generation delta median: -0.58%.
- Prefill delta median: -13.81%.
- GPU peak delta median: -0.02%.
- Every sample reached 4,096 generated tokens; the structural output-quality check found no repeated long paragraphs.
- The initial two pairs did not meet the early-stop stability limits, so a third alternating pair was added before the decision.

## Decision

**Do not integrate PR #28123 into the active configuration.**

The candidate did not cause a material median regression in 4K generation, but its 32K prefill median was 13.81% slower.  The local non-regression rule rejects a prefill regression greater than 3%.  The active executable and shortcut therefore remain unchanged.

## Publication hygiene

This report contains aggregate measurements only.  It excludes prompts, responses, commands, model paths, host identifiers, network addresses, timestamps, and raw logs.
