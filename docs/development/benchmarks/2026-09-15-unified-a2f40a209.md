# Unified a2f40a209 benchmark

## Release source and build scope

The application source for this release is
`a2f40a209a77d554a52db8d88780071609bba2a8`.  The release branch adds only the
existing artifact workflow, its public-data audit, this report, and CI artifact
portability corrections.  It does not alter llama.cpp application or backend
source files.

The measurements below used locally built `a2f40a209` executables: ROCm 10.0.0
for Qwen3.6 35B and Qwen3.8 27B, and Vulkan 1.4.341 for Qwen3.8 Flash Next,
Ling-3.0, and Laguna S 2.1.  The GitHub Actions artifacts are independently
built by CI for gfx1150; they are release binaries, not the executables used
for these measurements.

## Benchmark environment

| Item | Value |
| --- | --- |
| Input | 32,768-token programming prompt |
| Output measurement | One cache-miss request followed by two prompt-cache requests; natural EOS or 4,096 generated tokens, with a 300-second generation limit per request |
| Cache | Enabled for the two repeated requests |
| Common settings | Context 100,000; batch 2,048; K/V Q8; unified KV; Flash Attention; parallel 1; threads 10 |
| ROCm runtime used for measurement | ROCm 10.0.0, gfx1150 |
| Vulkan runtime used for measurement | Vulkan 1.4.341 on AMD RADV |
| Release artifact build | Linux ROCm 7.2.4 container, Windows ROCm 10.0.0, Linux/Windows Vulkan; HIP target gfx1150 |

## Performance results

PP is the cache-miss prefill rate.  TG is the arithmetic mean of all three
request generation rates.  Wall time is the sum of the three requests.

| Model | Backend | Draft method | PP tok/s | TG tok/s | Wall s | Generated tokens (cold/cache_1/cache_2) | 300-second limit |
| --- | --- | --- | ---: | ---: | ---: | --- | --- |
| Qwen3.6 35B | ROCm 10.0.0 | MTP n=4, N-gram, draft KV F16 | 450.295 | 22.9726 | 616.064 | 4096 / 4096 / 4096 | none |
| Qwen3.8 27B | ROCm 10.0.0 | DFlash2 n=4, draft KV Q8 | 110.370 | 7.1577 | 1200.799 | 2303 / 2102 / 2045 | all three requests |
| Qwen3.8 Flash Next | Vulkan | MTP n=3, p-min 0.75, draft KV Q8 | 94.020 | 12.2471 | 1251.211 | 3502 / 3673 / 3852 | all three requests |
| Ling-3.0 | Vulkan | none | 92.872 | 14.2880 | 1213.871 | 4096 / 4096 / 4096 | none |
| Laguna S 2.1 | Vulkan | none | 126.420 | 9.1239 | 1168.777 | 2812 / 2699 / 2703 | all three requests |

Flash Next uses mmap and lazy loading for the PLE shards on SSD, without host
PLE preload.  Its speculative output still has a recorded token-sequence
difference from the no-draft output; its result is a speed, startup, and
acceptance observation rather than an output-equivalence result.

## Change from previous release

`ece81775299946ab0c3988507c5107ac1a2ccb19` was the previous public release
source.  These rows use the current shortcut settings where a direct comparison
was available.

| Model | Current wall s | Previous wall s | Wall delta | Comparison scope |
| --- | ---: | ---: | ---: | --- |
| Qwen3.6 35B | 616.064 | 625.595 | -1.524% | ece source rebuilt with ROCm 10.0.0; MTP n=4 and N-gram |
| Qwen3.8 27B | 1200.799 | 1218.989 | -1.492% | ece source rebuilt with ROCm 10.0.0; DFlash2 n=4 and draft KV Q8 |
| Ling-3.0 | 1213.871 | 1190.101 | +1.997% | ece public Vulkan artifact |
| Laguna S 2.1 | 1168.777 | 1170.864 | -0.178% | ece public Vulkan artifact |
| Qwen3.8 Flash Next | — | — | — | ece lacks the required lazy-loading and matching MTP conditions |

The Qwen3.6 N-gram configuration reduced three-request wall time from 672.952 s
to 616.064 s (-8.454%) relative to the same `a2f40a209` executable with MTP n=4
and N-gram disabled.  All three requests generated 4,096 tokens, and the output
check found no short-period repeated-character loop, NaN, Inf, OOM, GPU reset,
or server crash.
