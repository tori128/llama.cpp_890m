PP is cache-miss prefill. TG is the arithmetic mean of the three request decode rates. A 300-second cutoff remains visible in the generated-token column.

Qwen3.8 Vulkan used the selected shortcut configuration and the Vulkan binary identified above. Its three responses had no NaN, Inf, crash, GPU reset, memory guard event, or process swap. The maximum run of one non-whitespace character and of one token was five in each response.

Flash Next uses mmap and lazy SSD loading with no host PLE preload. Its present MTP setting has a known output-token difference from target-only decoding; the row records measured runtime performance and is not an output-equivalence comparison.
