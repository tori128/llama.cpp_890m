## Benchmark environment

| Item | Value |
| --- | --- |
| Source | b641572bd5adcb9328ead026dd091fed42e544a7 |
| CPU / GPU | AMD Ryzen AI 9 HX 370 / Radeon 890M (gfx1150) |
| Input / output | 32,768-token input; 4,096-token cap; output cutoff 300 seconds after the first generated token |
| Measurement | One cache-miss request followed by two prompt-cache requests in one server process |
| Batch settings | Batch 2,048; u-batch 1,024 for Qwen3.6 and Qwen3.8; u-batch 512 for Flash Next, Ling-3.0, and Laguna S 2.1 |
| Cache / backend | Base K/V Q8_0, unified KV; Qwen3.6 ROCm 10.0.0/gfx1150; other models Vulkan |

PP is cache-miss prefill. TG is the arithmetic mean of the three request decode rates. The reference is the previous public release, `unified-09e863d22`.

The current Qwen3.8 and Flash Next measurements use the existing shortcut Vulkan binary. The current Ling and Laguna measurements use the existing shortcut Vulkan build, and Qwen3.6 uses the existing shortcut ROCm build. The release artifacts are built separately by GitHub Actions from the source commit above.

Flash Next uses mmap and lazy SSD loading with no host PLE preload. Its MTP output is measured as runtime performance; this table does not assert token-sequence equivalence with target-only decoding.
