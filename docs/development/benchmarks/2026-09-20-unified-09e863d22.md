# Unified 09e863d22 benchmark

## Benchmark environment

| Item | Value |
| --- | --- |
| Runtime source | `09e863d22dfee87f5236a7577439b7e332aba9c7` |
| Previous public release | `unified-a2f40a209` |
| Input | 32,768-token programming prompt |
| Output measurement | One cache-miss request followed by two prompt-cache requests; 4,096 generated tokens or 300 seconds per request |
| Cache | Enabled for the two repeated requests |
| Common settings | Context 100,000; batch 2,048; K/V Q8; unified KV; Flash Attention; parallel 1; threads 10 |
| Qwen3.8 27B | Vulkan; u-batch 1,024; DFlash2 n=4; draft KV Q8; `GGML_VK_DENSE_F16B=auto` |
| Qwen3.8 Flash Next | Vulkan; u-batch 512; MTP n=3; p-min 0.75; draft KV Q8; mmap/lazy SSD loading; no host PLE preload; `--no-repack` |

PP is the cache-miss prefill rate. TG is the arithmetic mean of the three
request generation rates. Wall time is the sum of the three requests.

## Performance results

| Model | Backend | Draft method | PP tok/s | TG tok/s | Wall s | Generated tokens (cold/cache_1/cache_2) | 300-second limit |
| --- | --- | --- | ---: | ---: | ---: | --- | --- |
| Qwen3.8 27B | Vulkan | DFlash2 n=4, draft KV Q8 | 83.915 | 8.1621 | 1294.345 | 2429 / 2429 / 2494 | all three requests |
| Qwen3.8 Flash Next | Vulkan | MTP n=3, p-min 0.75, draft KV Q8 | 78.931 | 12.3732 | 1317.547 | 3743 / 3689 / 3706 | all three requests |

Flash Next uses mmap and lazy loading for the PLE shards on SSD, without host
PLE preload. Its speculative output has a recorded token-sequence difference
from target-only decoding; this row records runtime performance.

## Comparison with previous public release

The previous rows use the published Vulkan asset from `unified-a2f40a209`.
Positive rate deltas are faster; negative wall deltas are shorter.

| Model | Current PP | Previous PP | PP delta | Current TG | Previous TG | TG delta | Current wall s | Previous wall s | Wall delta |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Qwen3.8 27B | 83.915 | 81.373 | +3.12% | 8.1621 | 6.6342 | +23.03% | 1294.345 | 1318.478 | -1.83% |
| Qwen3.8 Flash Next | 78.931 | 83.911 | -5.94% | 12.3732 | 8.8891 | +39.20% | 1317.547 | 1293.663 | +1.85% |

All six requests reached the 300-second limit. No NaN, Inf, OOM, GPU reset, or
server crash was observed. The total-wall deltas are within the project’s 3%
performance-change threshold.
