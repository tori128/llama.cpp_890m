## Measurement method

- 32,768 input tokens, one cache-miss request, and two prompt-cache requests in one server process.
- Response limit 4,096 tokens; generation measurement ends 300 seconds after the first output token. Every request in this comparison reached the 300-second limit.
- PP is the cold-request input processing rate. TG is the arithmetic mean of the three generation rates. Total wall is the sum of the three request wall times.
- Batch size 2,048.
- Qwen3.8 27B: Vulkan, u-batch 1,024, DFlash2 n=4, base and draft KV Q8_0, context 100,000, `GGML_VK_DENSE_F16B=auto`.
- Qwen3.8 Flash Next: Vulkan, u-batch 512, MTP n=3, p-min 0.75, base and draft KV Q8_0, context 100,000, mmap/lazy SSD loading, no host PLE preload, and `--no-repack`.
- Flash Next environment: `LLAMA_ATTN_ROT_DISABLE=1`, `LLAMA_QSA_GATHER=16384`, `LLAMA_MMAP_RANDOM=1`, `LLAMA_PLE_HOST_GATHER=0`, `GGML_VK_ASYNC_USE_TRANSFER_QUEUE=1`, and `GGML_VK_DISABLE_INTEGER_DOT_PRODUCT=1`.
- Prompt JSON SHA-256: `2afb1b771610cd93ed104996aaa128997cae096509cab0719fe96682c15a959b`; token-ID SHA-256: `f894660426f939b12279d9216747752f43ec8029ef8fb882ac9754d5796a335a`.
